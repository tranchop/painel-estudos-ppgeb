# Painel de Estudos PPGEB

Painel de estudos para a prova do Mestrado em Engenharia Biomédica (PPGEB/UNIVAP): contagem regressiva, progresso, horas e revisões. Dados salvos no navegador.

**App:** https://tranchop.github.io/painel-estudos-ppgeb/

Página única em HTML/CSS/JavaScript, sem dependências de build. Para rodar localmente, abra `index.html` no navegador.

> Observação: a sincronização com integrações do Claude só funciona dentro do Claude. No GitHub Pages o app usa armazenamento local do navegador.
